Вход для совладельцев

Изменения сохраняются прямо в репозиторий сайта на GitHub. Сайт обновится примерно через минуту после сохранения.

Как получить токен (один раз)

Совладелец (сайт не на вашем аккаунте):

  1. Владелец сайта добавляет вас: репозиторий — → Settings → Collaborators → Add people. Примите приглашение (придёт на почту и в уведомления GitHub).
  2. Откройте Settings → Developer settings → Tokens (classic) → Generate new token (classic).
  3. Note — любое, Expiration — срок. В Scopes отметьте только public_repo.
  4. Нажмите Generate token, скопируйте (начинается с ghp_) и вставьте сюда.

Владелец сайта (—) может вместо этого сделать токен только для этого сайта: Fine-grained tokens → Only select repositories → сайт → Contents: Read and write.

Никому не передавайте токен: с ним можно менять сайт. Если токен утёк — удалите его в тех же настройках GitHub.
