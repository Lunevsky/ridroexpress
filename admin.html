Вход для совладельцев

Изменения сохраняются прямо в репозиторий сайта на GitHub. Сайт обновится примерно через минуту после сохранения.

Как получить токен (один раз)
  1. Войдите в свой аккаунт GitHub (вас должны добавить в соавторы репозитория сайта).
  2. Откройте Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Resource owner — владелец репозитория (—). Repository access — Only select repositories → —.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Нажмите Generate token, скопируйте и вставьте сюда. Никому не передавайте токен.
● Есть несохранённые изменения
