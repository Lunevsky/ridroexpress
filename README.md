# Сайт ЧТУП «RidroExpress» · MTA Province #6

Статический сайт для GitHub Pages. Без сборки и зависимостей.

| Страница | Для кого |
|---|---|
| `index.html` | Пассажиры: поиск маршрутов, карты, остановки, проезд |
| `staff.html` | Сотрудники: ЗП, таблички, бинды, скриншоты, надбавки, правила, ПИВО |
| `admin.html` | Совладельцы: редактирование всех данных и загрузка карт |

## Данные
- `data/routes.json` — все маршруты (перевозчик, остановки, проезд, ЗП, табличка, бинды, надбавки, карта).
- `data/site.json` — тексты: организация, ссылки, правила, наказания, надбавки, раскраски, общие бинды, ПИВО.
- `assets/maps/` — карты маршрутов (`<id>.jpg`) и превью (`thumb/<id>.jpg`).

## Как совладельцы меняют данные
1. Владелец репозитория добавляет совладельцев: **Settings → Collaborators → Add people** (их GitHub-аккаунты).
2. Каждый совладелец один раз создаёт fine-grained токен: доступ только к этому репозиторию, **Contents: Read and write**.
3. Открыть `/admin.html`, вставить токен, править, нажать **«Сохранить на сайт»**. Сайт обновится примерно через минуту.

Права проверяет GitHub: без доступа к репозиторию сохранить ничего нельзя.

## Запуск локально
```bash
python -m http.server 8080
```
