# Сайт ЧТУП «RidroExpress» · MTA Province #6

Статический сайт для GitHub Pages. Данные автоматически дублируются с Google Диска.

| Страница | Для кого |
|---|---|
| `index.html` | Пассажиры: поиск маршрутов, карты, остановки, проезд |
| `staff.html` | Сотрудники: маршруты, ЗП, калькулятор ЗП, отчёты, список сотрудников, надбавки, правила, бинды, устав |
| `admin.html` | Совладельцы: то, чего нет на диске (город, конечные, примечания, тексты сайта) |

## Откуда данные
| Данные | Источник | Как попадает на сайт |
|---|---|---|
| Маршруты, ЗП, таблички, бинды маршрутов, надбавки, карты | Google-документы «Маршруты …» и «Заработные платы по маршрутам» | `tools/sync_drive.py` каждые 30 минут (GitHub Actions) → `data/routes.json`, `assets/maps/` |
| Общие бинды | документ «Бинды …» | то же → `data/binds.json` |
| Устав | документ «Устав …» | то же → `data/ustav.html`, `assets/ustav/` |
| Сотрудники, отчёты | таблица «ЧТУП «RidroExpress»» и форма «Отчет …» | напрямую со страницы через Apps Script (`tools/apps-script.gs`) — без банковских счетов |
| Город, конечные, примечания, маршруты вне документов | `data/manual.json` | админка |
| Тексты сайта, правила, ссылки, адрес Apps Script | `data/site.json` | админка |

**Диск главнее:** всё, что есть в документах, перезаписывается при синхронизации. Править — в документах.

Синхронизация вручную: **Actions → «Синхронизация с Google Диском» → Run workflow**, или локально:
```bash
pip install python-docx==1.2.0 pillow==12.3.0
python tools/sync_drive.py
```

## Выплаты (в таблице, для администрации)
Скрипт `tools/apps-script.gs` в таблице считает каждый новый отчёт и пишет строку в лист «Выплаты»:
ЗП за рейсы, штраф окраски, надбавка за тип автобуса (угадывается по автобусу, спорное помечено «Проверить»), за пассажиров, возмещение (вписывает админ), Итого, Статус.
1. Админ проверяет доказательства → статус «Одобрен» / «Отклонён». Можно поправить маршрут/круги и нажать «Ridro → Пересчитать выделенные строки».
2. Раз в неделю: «Ridro → Сформировать ведомость за неделю» — сумма по каждому сотруднику (одобренные, ещё не выплаченные, до конца прошлой недели) с номером счёта.
3. После перевода: «Ridro → Отметить ведомость выплаченной».
Статусы и суммы видны водителям на сайте (без счетов).

## Список сотрудников и отчёты (один раз)
Таблица закрыта, поэтому её данные отдаёт скрипт внутри таблицы — только разрешённые столбцы.
Инструкция по установке — в начале `tools/apps-script.gs`. Полученный адрес `…/exec` вставить в админке:
«Тексты и правила» → «Адрес данных таблицы».

## Как совладельцы меняют данные на сайте
1. Владелец репозитория добавляет совладельцев: **Settings → Collaborators → Add people**.
2. Совладелец принимает приглашение и создаёт **классический** токен (Tokens (classic), scope **public_repo**) — fine-grained токены не работают с чужим личным репозиторием. Владелец может использовать fine-grained (только этот репозиторий, Contents: Read and write).
3. Открыть `/admin.html`, вставить токен, править, нажать **«Сохранить на сайт»**.
